### 10. Temperature & Top-P Control 🎚️

Fine-tune AI creativity and focus:

#### Temperature (0-1)
- **0** = Very factual, deterministic
- **0.3-0.5** = Focused, reliable recommendations
- **0.7** = Balanced (default)
- **0.9-1** = Creative, surprising suggestions

#### Top-P (0.1-1)
- **0.1** = Very focused, conservative
- **0.5** = Balanced diversity
- **0.9** = Full diversity, unexpected picks

#### Use Cases
- **For Factual Recommendations**: Lower temperature (0.3-0.5)
- **For Balanced**: Default (0.7, 0.9)
- **For Creative Exploration**: Higher temperature (0.8-1)

**Example:**
```
User adjusts Temperature to 0.9
"Surprise me with an unusual book recommendation"
AI: Uses higher creativity for surprising suggestions
```
